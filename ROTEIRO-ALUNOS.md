# Roteiro de apresentação — 5 alunos

Ligue o **Modo apresentação** (botão "🎤 Apresentar") e use as setas ← → para trocar de seção.
Sugestão: ensaiem com as próprias palavras; as falas abaixo são só um ponto de partida.

---

## Aluno 1 — VS Code (com demo ao vivo)
**Mostrar:** seção "VS Code" (editor simulado) e depois o VS Code de verdade com Live Server.

> "Oi, pessoal! Eu vou mostrar onde a mágica acontece: o VS Code. Ele é como uma **oficina**: tem a bancada e todas as ferramentas para montar um site. Olha só: eu mudo a cor aqui no `:root`, salvo, e o site muda na hora! Quem escreve o código é o VS Code, quem executa é o navegador."

**Demo ao vivo (3 edições):** cor no `:root` (`--verde-600`), texto do hero (`index.html`), duração de uma animação (`--dur-forma` ou `.seta-rolar` no `style.css`).

## Aluno 2 — HTML
**Mostrar:** seção "Como foi feito" → aba **HTML** (o cartão real aparece ali).

> "Eu vou falar do HTML. Ele é o **esqueleto** do corpo: sem ossos nada fica de pé. Cada pedacinho da página é uma 'tag': `<h3>` é um título, `<p>` é um parágrafo, `<button>` é um botão. Este cartão que vocês estão vendo é feito só com essas peças. Se eu apagar uma tag, a peça some da página!"

## Aluno 3 — CSS
**Mostrar:** aba **CSS**: arrastar o controle de duração da bolinha.

> "O CSS é a **roupa e a dança** da página. É ele que escolhe verde, tamanho, bordas arredondadas e também faz as coisas se mexerem. Vejam essa bolinha: o `@keyframes` diz 'sobe, desce'. Eu arrasto aqui e mudo a duração: mais rápido, mais devagar. Uma linha muda tudo!"

## Aluno 4 — JavaScript
**Mostrar:** aba **JS**: clicar em "Executar" e ver o número subir até 100. Depois o Laboratório ao vivo.

> "O JavaScript é o **cérebro**: ele pensa, decide e manda o corpo agir. Este código é a função que faz os números subirem, e é o código de verdade deste site. Quando eu clico em 'Executar', o cérebro conta de 0 até 100. Sem JavaScript, a página só ficaria parada, bonita mas sem reação."

## Aluno 5 — Deploy (colocar no ar)
**Mostrar:** aba **No ar** (fluxo animado) e a legenda do VS Code ("VS Code escreve, navegador executa, GitHub guarda, Vercel publica").

> "Agora, como o site chega até vocês? Pensem numa **pizzaria**: a cozinha é o meu computador, o GitHub é o estoque onde a receita fica guardada, e a Vercel é o motoboy que entrega em casa. Eu envio o código com `git push`, a Vercel percebe e publica sozinha, e no final recebo um link que qualquer pessoa abre no celular."

---

## E se perguntarem: "Vocês escreveram tudo?"

> "Usamos inteligência artificial como **apoio**, igual a uma calculadora ou um professor particular: ela ajudou a montar a primeira versão e a acelerar o trabalho. Mas nós sabemos explicar cada parte: o que é HTML, CSS e JavaScript, como o site vai para o ar. E conseguimos mudar sozinhos as cores, os textos e a duração das animações, como vocês viram ao vivo. Usar IA bem, entendendo o que ela entrega, faz parte do que a gente aprende no curso."

*Dica: só digam isso se for verdade para o grupo. Treinem mudando uma coisa sem ajuda antes de apresentar.*
